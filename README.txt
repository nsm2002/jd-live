BUTLER FIELD LIVE — GITHUB PAGES FILES

Upload index.html to a GitHub repository and enable GitHub Pages.
The site will use the permanent Butler Field HLS stream URL.

Suggested repository name: jd-live

After Pages is enabled, your public URL will look like:
https://YOUR-GITHUB-USERNAME.github.io/jd-live/

If the direct HLS stream is later blocked for non-YourGameCam origins,
the Fallback button opens the official YourGameCam page.
